# 📊 Superstore Sales Data Analysis

## Project Overview

This project analyzes Superstore sales data using Python and Jupyter Notebook. The goal of this project is to identify sales trends, customer behavior, product performance, and business insights.

## Dataset Information

- Total Records: 9,994
- Total Columns: 18

## Tools and Libraries Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Key Insights

- Technology category generated the highest sales.
- High discounts reduced profitability.
- November and December were peak sales months.
- West region contributed the highest revenue.
- Some products generated losses.

## Visualizations

- Category-wise Sales
- Category-wise Profit
- Monthly Sales Trend
- Top 10 Products
- Top 10 Customers
- Region-wise Sales
- Sales vs Profit
- Discount vs Profit

## Business Recommendations

1. Increase investment in the Technology category.
2. Review the pricing strategy for high-discount products.
3. Investigate loss-making products.
4. Increase marketing during peak seasons.
5. Introduce a loyalty program for top customers.
